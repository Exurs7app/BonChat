# BonChat على GitHub Pages

هذه الحزمة معدّة للنشر كصفحة GitHub Pages. جميع الملفات والأيقونات موجودة مباشرة في الجذر، بلا مجلدات فرعية.
المسارات نسبية لتعمل سواء نُشرت الصفحة في جذر النطاق أو داخل مسار المستودع.

## النشر

1. أنشئ مستودعًا جديدًا على GitHub.
2. ارفع **الملفات مباشرةً** إلى جذر المستودع، بحيث يكون `index.html` في الجذر.
3. افتح **Settings → Pages**.
4. اختر **Deploy from a branch**، ثم الفرع `main` والمجلد `/(root)`، واضغط **Save**.
5. بعد اكتمال النشر، افتح رابط GitHub Pages الذي يظهر في صفحة Pages.

## التثبيت في المتصفحات

1. افتح رابط GitHub Pages المنشور عبر HTTPS وانتظر تحميل الصفحة مرة واحدة.
2. من إعدادات BonChat اختر **تثبيت التطبيق**. سيظهر مربع التثبيت الأصلي في المتصفحات التي تدعمه.
3. إذا لم يظهر مربع أصلي، يعرض BonChat خطوات الإضافة المناسبة للمتصفح والجهاز. على iPhone/iPad تتم الإضافة من قائمة المشاركة، وعلى Android من قائمة المتصفح.

لا يوجد أمر تثبيت موحد يمكن للموقع فرضه على كل المتصفحات؛ يختلف الدعم وطريقة الإضافة حسب المتصفح ونظام التشغيل. على Android، يظهر التطبيق في المشغّل/درج التطبيقات عندما يوفّر المتصفح تثبيت PWA ويقبل المستخدم التثبيت. على iPhone/iPad يظهر على الشاشة الرئيسية.
