# BonChat على GitHub Pages

هذه الحزمة معدّة للنشر كصفحة GitHub Pages. جميع الملفات والأيقونات موجودة مباشرة في الجذر، بلا مجلدات فرعية.
المسارات نسبية لتعمل سواء نُشرت الصفحة في جذر النطاق أو داخل مسار المستودع.

## النشر

1. أنشئ مستودعًا جديدًا على GitHub.
2. ارفع **الملفات مباشرةً** إلى جذر المستودع، بحيث يكون `index.html` في الجذر.
3. افتح **Settings → Pages**.
4. اختر **Deploy from a branch**، ثم الفرع `main` والمجلد `/(root)`، واضغط **Save**.
5. بعد اكتمال النشر، افتح رابط GitHub Pages الذي يظهر في صفحة Pages.

## التثبيت على Android من Chrome

1. افتح رابط GitHub Pages المنشور في Chrome على الهاتف، وانتظر تحميل الصفحة مرة واحدة.
2. من إعدادات BonChat اختر **تثبيت التطبيق**، ثم وافق على نافذة Chrome.
3. إذا لم تظهر النافذة، افتح قائمة Chrome `⋮` واختر **تثبيت التطبيق**. قد يظهر في بعض الإصدارات باسم **إضافة إلى الشاشة الرئيسية**.

يجب استخدام رابط `https://` المنشور، لا فتح ملف HTML محليًا. بعد قبول التثبيت، يضيف Android التطبيق إلى المشغّل/درج التطبيقات بحسب إصدار الجهاز وواجهة الشركة المصنّعة.
